# BrightSprout attribution and notices

BrightSprout is an original application inspired by a review of open-source
educational and game projects. No source files, artwork, sound files, or
repository copy were copied into the application.

## Reviewed repositories

The following public repositories were reviewed as implementation and product
references:

- https://github.com/sojinantony01/brain-development-games
- https://github.com/schurick1502/Math4Kids
- https://github.com/tamakiramimy/kids-learning-games
- https://github.com/cnotv/kid-games
- https://github.com/fotisoikonomou/react-memory-game
- https://github.com/cmmusni/math-mash
- https://github.com/JesseRWeigel/battlemath
- https://github.com/satraul/matheor
- https://github.com/HildoBijl/stepwise
- https://github.com/rahulvelapure/focus-adventure
